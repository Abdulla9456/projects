# Практические работы · Абдулла

Отдельный учебный проект **КОНТУР**. Четыре последовательные frontend-практики и четыре самостоятельные backend-практики. Инструкции запуска — в папке каждого задания.

| Практика | Содержание |
|---|---|
| frontend-1-practice | HTML/CSS по собственному макету |
| frontend-2-practice | Интерактивный календарь на JavaScript |
| frontend-3-practice | Перенос страницы на React |
| frontend-4-practice | React, fetch и имитационный сервер |
| backend-1-practice | Проверка и создание записи клиента |
| backend-2-practice | API категорий |
| backend-3-practice | Мастера в SQLite |
| backend-4-practice | Валидация и сохранение услуг |

[Открыть прототип Figma](https://www.figma.com/proto/ru589r9AINfW33nPKPVVdE/?node-id=3003-2616&starting-point-node-id=3003%3A2616). Все данные учебные; реальных записей и платежей приложения не создают. Сервер frontend-4 и конфигурация React/Vite взяты из учебного шаблона tensor-school/learn-web-dev; интерфейс и клиентская логика написаны для КОНТУРА.
