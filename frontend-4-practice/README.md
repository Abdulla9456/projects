# Практика 4 · КОНТУР

Данные приходят через fetch: GET /api/booking/today и GET /api/slots?day=&month=&year=. Есть начальная загрузка, загрузка слотов, ошибки с повтором, таймаут 10 с и отмена устаревшего запроса. Клиент не содержит локального расписания.

## Запуск

Node.js 22.12+ / 24+. Выполните `npm ci`, затем `npm run dev`. Проверки: `npm run lint`, `npm test`, `npm run build`.

## Ручная проверка

Учебное «сегодня» — **16 ноября 2026**, как в макете. Для JS/React: при старте выбран этот день, время ещё не выбрано. Выберите 14:30 — обновится нижняя панель и станет доступно продолжение. Выберите 17 ноября — время сбросится, появится отсутствие окон. Выберите 18 ноября — снова доступны интервалы. Даты до 16 ноября отключены. Листайте месяцы через декабрь: год должен стать 2027. Кнопка продолжения выводит итог выбора; запись в реальный салон не отправляется.

## Асинхронная версия

`server/server.js` и конфигурация Vite взяты из шаблона курса без изменений. В `server/database.js` заменены только данные: текущая дата и два набора интервалов. Месяц 0-индексный. Задержка ответа — 500 мс. Проверяйте полный сценарий через dev-сервер: `vite preview` сам по себе API не запускает. В Network должны быть отдельные запросы today и slots. Быстро переключите 16 → 17 → 18 ноября: итоговое расписание должно относиться к последней дате. При остановленном сервере появляется ошибка; после запуска можно повторить запрос.
