# Практика 3 · КОНТУР

Та же страница перенесена на React: отдельные компоненты, useState, JSX, списки с key и обработчики onClick. Ручная работа с DOM не используется.

## Макет

[Прототип Figma](https://www.figma.com/proto/ru589r9AINfW33nPKPVVdE/?node-id=3003-2616&starting-point-node-id=3003%3A2616) · [экран даты и времени](https://www.figma.com/design/ru589r9AINfW33nPKPVVdE/?node-id=3003-3033).

Кремовый фон, зелёный акцент, Manrope для интерфейса и Lora для заголовков. Шрифты загружаются с Google Fonts; без сети используются Arial/Georgia. Контакты демонстрационные.

## Запуск

Node.js 22.12+ / 24+. Выполните `npm ci`, затем `npm run dev`. Проверки: `npm run lint`, `npm test`, `npm run build`.

## Ручная проверка

Учебное «сегодня» — **16 ноября 2026**, как в макете. Для JS/React: при старте выбран этот день, время ещё не выбрано. Выберите 14:30 — обновится нижняя панель и станет доступно продолжение. Выберите 17 ноября — время сбросится, появится отсутствие окон. Выберите 18 ноября — снова доступны интервалы. Даты до 16 ноября отключены. Листайте месяцы через декабрь: год должен стать 2027. Кнопка продолжения выводит итог выбора; запись в реальный салон не отправляется.
